## 6. Swap the First n Characters of Two Strings

**Practical:** Write a program to swap the first n characters of two strings.

### Code

```python
s1 = input("Enter first string: ")
s2 = input("Enter second string: ")
n = int(input("Enter n: "))

new1 = s2[:n] + s1[n:]
new2 = s1[:n] + s2[n:]

print("After swapping:", new1, new2)
```
### OUTPUT
<img width="1920" height="253" alt="6" src="https://github.com/user-attachments/assets/df525cd9-9f78-49cb-b1bc-09634756b43f" />


### Explanation

`s[:n]` gives the first n characters and `s[n:]` gives the rest. Each new string takes the first n characters from the *other* string and keeps its own remaining part. For example, with `s1 = "void"`, `s2 = "dust"` and `n = 2`:

```
new1 = "du" + "id" = "duid"
new2 = "vo" + "st"  = "vost"
```

If n is larger than a string's length, slicing simply takes the whole string, so there is no error.

## 7. Indices of All Occurrences of a Substring

**Practical:** Write a function that accepts two strings and returns the indices of all the occurrences of the second string in the first string as a list. If the second string is not present in the first string then it should return -1.

### Code

```python
def find_all(s, sub):
    indices = []
    start = 0
    while True:
        pos = s.find(sub, start)
        if pos == -1:
            break
        indices.append(pos)
        start = pos + 1
    return indices if indices else -1

a = input("Enter first string: ")
b = input("Enter second string: ")
print(find_all(a, b))
```
### OUUTPUT
<img width="1920" height="265" alt="7" src="https://github.com/user-attachments/assets/db541b34-6c0f-421c-99f6-456db9bf303b" />


### Explanation

`s.find(sub, start)` returns the index of the next match at or after `start`, or `-1` if there is none. Each time a match is found, its index is stored and the search restarts from `pos + 1`, so overlapping matches are also found. When no more matches exist, the loop stops. If the list is still empty, the function returns `-1` as the question requires. For example, `find_all("banana", "ana")` returns `[1, 3]`.

## 8. Cubes of Even Integers from a Mixed List

**Practical:** Write a program to create a list of the cubes of only the even integers appearing in the input list (may have elements of other types also) using the following:

- a. `for` loop
- b. list comprehension

### Code

```python
lst = [1, 2, "hello", 4, 3.5, 6, True, 7, "8", 10]

# a. Using for loop
result1 = []
for x in lst:
    if isinstance(x, int) and not isinstance(x, bool) and x % 2 == 0:
        result1.append(x ** 3)
print("Using for loop:", result1)

# b. Using list comprehension
result2 = [x ** 3 for x in lst
           if isinstance(x, int) and not isinstance(x, bool) and x % 2 == 0]
print("Using list comprehension:", result2)
```
### OUTPUT
<img width="1920" height="219" alt="8" src="https://github.com/user-attachments/assets/7fefc8da-dc04-42eb-8b5c-3922ca3b9753" />


### Explanation

The list contains strings and floats too, so each element is first checked with `isinstance(x, int)`. This avoids errors from doing `%` or `**` on strings. `not isinstance(x, bool)` is needed because in Python `True` counts as the integer 1, so booleans are excluded explicitly. Only elements that pass and are even (`x % 2 == 0`) get cubed. Part (b) is the same logic written in one line: `[expression for item in list if condition]`. Both give `[8, 64, 216, 1000]`.

## 9. File Handling

**Practical:** Write a program to read a file and:

- a. Print the total number of characters, words and lines in the file.
- b. Calculate the frequency of each character in the file. Use a variable of dictionary type to maintain the count.
- c. Print the words in reverse order.
- d. Copy even lines of the file to a file named `File1` and odd lines to another file named `File2`.

### Code

```python
fname = input("Enter file name: ")

with open(fname, "r") as f:
    lines = f.readlines()

text = "".join(lines)

# a. Total characters, words and lines
print("Characters:", len(text))
print("Words:", len(text.split()))
print("Lines:", len(lines))

# b. Frequency of each character
freq = {}
for ch in text:
    if ch in freq:
        freq[ch] += 1
    else:
        freq[ch] = 1
print("Character frequency:", freq)

# c. Words in reverse order
words = text.split()
print("Words in reverse:", " ".join(words[::-1]))

# d. Even lines to File1, odd lines to File2
with open("File1", "w") as f1, open("File2", "w") as f2:
    for i, line in enumerate(lines, 1):
        if i % 2 == 0:
            f1.write(line)
        else:
            f2.write(line)
```
### OUTPUT
<img width="1920" height="374" alt="9" src="https://github.com/user-attachments/assets/67f8e0ab-771f-485d-84df-773ed3120ac0" />


### Explanation

- **Reading:** `with open(...)` opens the file and closes it automatically. `readlines()` gives a list where each element is one line.
- **a:** `len(text)` counts every character (including spaces and newlines), `text.split()` breaks the text into words, and `len(lines)` counts the lines.
- **b:** `freq` is a dictionary with each character as the key and its count as the value. If the character is already a key, its count goes up by 1; otherwise it is added with count 1.
- **c:** `words[::-1]` reverses the list of words, and `" ".join(...)` turns it back into a single line.
- **d:** `enumerate(lines, 1)` numbers the lines starting from 1. Even-numbered lines go to `File1` and odd-numbered lines go to `File2`. Mode `"w"` creates the file for writing.

## 10. Dictionary of Numbers and Their Cubes

**Practical:** Write a function that prints a dictionary where the keys are numbers between 1 and 5 and the values are cubes of the keys.

### Code

```python
def print_cubes():
    d = {}
    for i in range(1, 6):
        d[i] = i ** 3
    print(d)

print_cubes()
```
### OUTPUT
<img width="1920" height="293" alt="10" src="https://github.com/user-attachments/assets/044cedf4-aea6-4a4a-afa9-ef1d89a4b09b" />


### Explanation

The loop runs for `i = 1` to `5` (`range(1, 6)` stops before 6). For each `i`, the key is the number and the value is its cube, so `d[i] = i ** 3`. Output: `{1: 1, 2: 8, 3: 27, 4: 64, 5: 125}`. A shorter way is a dictionary comprehension: `{i: i**3 for i in range(1, 6)}`.
