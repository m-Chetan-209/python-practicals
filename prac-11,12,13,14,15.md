## 11. Tuple Operations

**Practical:** Consider a tuple `t1 = (1, 2, 5, 7, 9, 2, 4, 6, 8, 10)`. Write a program to perform the following operations:

- a. Print half the values of the tuple in one line and the other half in the next line.
- b. Print another tuple whose values are even numbers in the given tuple.
- c. Concatenate a tuple `t2 = (11, 13, 15)` with `t1`.
- d. Return maximum and minimum value from this tuple.

### Code

```python
t1 = (1, 2, 5, 7, 9, 2, 4, 6, 8, 10)

# a. Print half the values in one line and the other half in the next
mid = len(t1) // 2
print(t1[:mid])
print(t1[mid:])

# b. Tuple of even numbers
evens = tuple(x for x in t1 if x % 2 == 0)
print("Even numbers:", evens)

# c. Concatenate t2 with t1
t2 = (11, 13, 15)
t3 = t1 + t2
print("Concatenated:", t3)

# d. Maximum and minimum
print("Max:", max(t1))
print("Min:", min(t1))
```
### OUTPUT
<img width="1920" height="327" alt="11" src="https://github.com/user-attachments/assets/a7b365ad-7175-4098-867b-a31a4c396a1b" />


### Explanation

- **a:** `len(t1) // 2` gives the middle index (10 values, so 5). `t1[:5]` is the first half and `t1[5:]` is the second half.
- **b:** A tuple can't be changed after creation, so a new one is built. The generator `(x for x in t1 if x % 2 == 0)` picks the even values and `tuple()` converts the result into a tuple.
- **c:** `+` joins two tuples into a new tuple. `t1` itself stays unchanged.
- **d:** `max()` and `min()` work directly on a tuple.

## 12. Class `Employee`

**Practical:** Define a class `Employee` that stores information about employees in the company. The class should contain the following:

1. Data members: `count` (to keep a record of all the objects being created for this class) and for every employee: an employee number, Name, Dept, Basic, DA and HRA.
2. Function members:
   - a. `__init__` method to initialize and/or update the members. Add statements to ensure that the program is terminated if any of Basic, DA and HRA is set to a negative value.
   - b. function `salary`, that returns salary as the sum of Basic, DA and HRA.
   - c. `__del__` function to decrease the number of objects created for the class.
   - d. `__str__` function to display the details of an employee along with the salary of an employee in a proper format.

### Code

```python
import sys

class Employee:
    count = 0                      # class variable, shared by all objects

    def __init__(self, empno, name, dept, basic, da, hra):
        Employee.count += 1
        if basic < 0 or da < 0 or hra < 0:
            print("Error: Basic, DA and HRA cannot be negative.")
            sys.exit()
        self.empno = empno
        self.name = name
        self.dept = dept
        self.basic = basic
        self.da = da
        self.hra = hra

    def salary(self):
        return self.basic + self.da + self.hra

    def __del__(self):
        Employee.count -= 1

    def __str__(self):
        return (f"Employee No : {self.empno}\n"
                f"Name        : {self.name}\n"
                f"Department  : {self.dept}\n"
                f"Basic       : {self.basic}\n"
                f"DA          : {self.da}\n"
                f"HRA         : {self.hra}\n"
                f"Salary      : {self.salary()}")

e1 = Employee(101, "Aman", "IT", 30000, 5000, 8000)
e2 = Employee(102, "Riya", "HR", 28000, 4500, 7000)

print(e1)
print()
print(e2)
print("Employees:", Employee.count)    # 2

del e2
print("Employees:", Employee.count)    # 1
```

### Explanation (class concepts) and OUTPUT:

- **Class and object:** `Employee` is the blueprint. `e1` and `e2` are objects (instances) made from it, each holding its own data.
- **`count = 0` (class variable):** It is written directly inside the class, not inside a method, so there is one copy shared by all objects. It is accessed as `Employee.count`. This is how the class keeps track of how many objects exist.
- **Instance variables:** `self.empno`, `self.name`, etc. belong to one specific object. `e1.name` is "Aman" while `e2.name` is "Riya". `self` means "the object being worked on".
- **`__init__` (constructor):** It runs automatically every time an object is created. It increases `count` by 1, then checks that Basic, DA and HRA are not negative. If any is negative, it prints an error and `sys.exit()` terminates the program, as the practical requires. Otherwise the values are stored in the object.
- **`salary()`:** An ordinary method. It returns Basic + DA + HRA using the object's own values.
- **`__del__` (destructor):** It runs when an object is deleted (for example with `del e2`) or is no longer used. It reduces `count` by 1. That is why the count goes from 2 to 1 after `del e2`.
- **`__str__`:** It controls what `print(e1)` shows. Without it, print would show something unreadable like `<__main__.Employee object at 0x...>`. Here it returns a neatly formatted string with all the details and the salary.

`count` is increased before the negative check so that `__del__` (which always subtracts 1) stays consistent even if the program stops during construction.

## 13. Class `2DPoint`

**Practical:** Write a program to define a class `2DPoint` with coordinates x and y as attributes. Create relevant methods and print the objects. Also define a method `distance` to calculate the distance between any two point objects.

### Code

```python
import math

class Point2D:
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def distance(self, other):
        return math.sqrt((self.x - other.x) ** 2 + (self.y - other.y) ** 2)

p1 = Point2D(1, 2)
p2 = Point2D(4, 6)

print("Point 1:", p1)
print("Point 2:", p2)
print("Distance:", p1.distance(p2))     # 5.0
```

### Explanation (class concepts) and OUTPUT:

- **Class name:** Python names can't start with a digit, so `2DPoint` is not allowed. `Point2D` is used instead (and `Point3D` in the next program).
- **Attributes:** `x` and `y` are the coordinates, stored on each object by `__init__`. The default values `x=0, y=0` mean `Point2D()` creates the point (0, 0).
- **`__str__`:** Makes `print(p1)` display `(1, 2)`, which is the "print the objects" part of the practical.
- **`distance(self, other)`:** It is called on one point and receives the other point as `other`. So `p1.distance(p2)` has `self = p1` and `other = p2`. It uses the distance formula √((x₂−x₁)² + (y₂−y₁)²). For (1, 2) and (4, 6): √(9 + 16) = √25 = 5.0.

## 14. Class `3DPoint` (Inheritance)

**Practical:** Inherit the above class to create a `3DPoint` with additional attribute z. Override the method defined in `2DPoint` class, to calculate distance between two points of the `3DPoint` class.

### Code

```python
import math

class Point2D:
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y

    def __str__(self):
        return f"({self.x}, {self.y})"

    def distance(self, other):
        return math.sqrt((self.x - other.x) ** 2 + (self.y - other.y) ** 2)


class Point3D(Point2D):
    def __init__(self, x=0, y=0, z=0):
        super().__init__(x, y)
        self.z = z

    def __str__(self):
        return f"({self.x}, {self.y}, {self.z})"

    def distance(self, other):
        return math.sqrt((self.x - other.x) ** 2 +
                         (self.y - other.y) ** 2 +
                         (self.z - other.z) ** 2)

a = Point3D(1, 2, 3)
b = Point3D(4, 6, 15)

print("Point A:", a)
print("Point B:", b)
print("Distance:", a.distance(b))      # 13.0
```

### Explanation (class concepts), OUTPUT:

- **Inheritance:** `class Point3D(Point2D)` makes `Point3D` the child (subclass) of `Point2D`. It automatically gets `x`, `y` and the methods of the parent, so only what is new needs to be written.
- **`super().__init__(x, y)`:** Calls the parent's constructor to set `x` and `y`, so that code isn't repeated. The child then adds its own attribute `self.z = z`.
- **Method overriding:** The child defines `distance` and `__str__` again with the same names. When called on a `Point3D` object, Python uses the child's version, which includes z. This is what "override the method" means in the practical.
- **Calculation:** For (1, 2, 3) and (4, 6, 15), the differences are 3, 4 and 12, so √(9 + 16 + 144) = √169 = 13.0.

> **Note:** When keeping programs 13 and 14 in one file, the `Point2D` class must come first, since `Point3D` depends on it.

## 15. Name Validation with Exceptions

**Practical:** Write a program to accept a name from a user. Raise and handle appropriate exception(s) if the text entered by the user contains digits and/or special characters.

### Code

```python
class DigitError(Exception):
    pass

class SpecialCharError(Exception):
    pass

try:
    name = input("Enter your name: ")

    if any(ch.isdigit() for ch in name):
        raise DigitError

    if any(not (ch.isalpha() or ch.isspace()) for ch in name):
        raise SpecialCharError

except DigitError:
    print("Error: Name should not contain digits.")

except SpecialCharError:
    print("Error: Name should not contain special characters.")

else:
    print("Valid name:", name)

finally:
    print("Program ended.")
```
### OUTPUT
<img width="1920" height="290" alt="15" src="https://github.com/user-attachments/assets/597e4010-202b-4dc0-8b45-60c8f3c47931" />


### Explanation

- **Custom exceptions:** `DigitError` and `SpecialCharError` are our own exception classes. They inherit from Python's built-in `Exception` class, and `pass` means they need no extra code. Having two separate exceptions lets the program tell the two kinds of mistake apart.
- **`try` block:** It only contains the work and the checks, and no error messages. It takes the name as input and tests it. If the name breaks a rule, `raise` throws the matching exception and the rest of the `try` block is skipped.
- **Digit check:** `any(ch.isdigit() for ch in name)` is `True` if at least one character is a digit, so `DigitError` is raised.
- **Special character check:** A character is allowed only if it is a letter or a space (so names like "Aman Kumar" are accepted). If any character is neither, `SpecialCharError` is raised.
- **`except` blocks:** The error messages live here. Each `except` catches one kind of exception and prints its message, so the program doesn't crash.
- **`else` block:** It runs only when the `try` block finishes with no exception, so it prints the valid name.
- **`finally` block:** It always runs, whether or not an error occurred. Here it prints "Program ended." In real programs it is used for cleanup such as closing files.
