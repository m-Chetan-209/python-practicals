## 1. Roots of a Quadratic Equation

**Practical:** Write a program to find the roots of a quadratic equation.

### Code

```python
import cmath

a = float(input("Enter a: "))
b = float(input("Enter b: "))
c = float(input("Enter c: "))

if a == 0:
    print("Not a quadratic equation")
else:
    d = b**2 - 4*a*c
    r1 = (-b + cmath.sqrt(d)) / (2*a)
    r2 = (-b - cmath.sqrt(d)) / (2*a)
    print("Roots:", r1, r2)
```
### OUTPUT
<img width="1694" height="232" alt="1" src="https://github.com/user-attachments/assets/900a3cde-a52d-43a6-9b43-68db43b41353" />

### Explanation

The discriminant `d = b² − 4ac` decides the type of roots. `cmath.sqrt` is used instead of `math.sqrt` so a negative `d` gives complex roots instead of an error. If `a == 0`, the equation is linear, so the program stops with a message.

## 2. Prime Number Operations

**Practical:** Write a program to accept a number 'n' and:

- a. Check if 'n' is prime
- b. Generate all prime numbers till 'n'
- c. Generate first 'n' prime numbers

This program may be done using functions.

### Code

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

def primes_till(n):
    return [i for i in range(2, n + 1) if is_prime(i)]

def first_n_primes(n):
    result, num = [], 2
    while len(result) < n:
        if is_prime(num):
            result.append(num)
        num += 1
    return result

n = int(input("Enter n: "))
print(n, "is prime" if is_prime(n) else "is not prime")
print("Primes till n:", primes_till(n))
print("First n primes:", first_n_primes(n))
```
### OUTPUT
<img width="1920" height="274" alt="2" src="https://github.com/user-attachments/assets/98238d52-2ea5-4c0a-a7b8-dfe126d2bf90" />

### Explanation

`is_prime` only checks divisors up to √n, which is faster. `primes_till` reuses it for every number up to n. `first_n_primes` keeps counting upward with a `while` loop until it has collected n primes.

## 3. Pyramid and Reverse Pyramid of `*`

**Practical:** Write a program to create a pyramid of the character `*` and a reverse pyramid.

### Code

```python
n = int(input("Enter number of rows: "))

print("Pyramid:")
for i in range(1, n + 1):
    print(" " * (n - i) + "* " * i)

print("Reverse pyramid:")
for i in range(n, 0, -1):
    print(" " * (n - i) + "* " * i)
```
### OUTPUT
<img width="1920" height="531" alt="3" src="https://github.com/user-attachments/assets/ed69263a-8cd4-4440-9df9-dd37e009b3f7" />

### Explanation

For row `i`, the program prints `n - i` spaces to center it, then `i` stars. The reverse pyramid is the same loop run backwards (`range(n, 0, -1)`).

## 4. Character Classification

**Practical:** Write a program that accepts a character and performs the following:

- a. Print whether the character is a letter or numeric digit or a special character.
- b. If the character is a letter, print whether the letter is uppercase or lowercase.
- c. If the character is a numeric digit, print its name in text (e.g., if input is 9, output is NINE).

### Code

```python
ch = input("Enter a character: ")[0]
names = ["ZERO", "ONE", "TWO", "THREE", "FOUR",
         "FIVE", "SIX", "SEVEN", "EIGHT", "NINE"]

if ch.isalpha():
    print("Letter")
    print("Uppercase" if ch.isupper() else "Lowercase")
elif ch.isdigit():
    print("Digit")
    print(names[int(ch)])
else:
    print("Special character")
```
### OUTPUT
<img width="1920" height="202" alt="4" src="https://github.com/user-attachments/assets/279ada24-2ea9-4ab1-adcf-3588d215bdda" />

### Explanation

`isalpha()`, `isupper()` and `isdigit()` are built-in string methods. The digit itself is used as an index into the `names` list, so `9` gives `names[9]` = `"NINE"`. `[0]` makes sure only the first character is used.

## 5. String Operations

**Practical:** Write a program to perform the following operations on a string:

- a. Find the frequency of a character in a string.
- b. Replace a character by another character in a string.
- c. Remove the first occurrence of a character from a string.
- d. Remove all occurrences of a character from a string.

### Code

```python
s = input("Enter a string: ")
c = input("Enter character to work with: ")
new = input("Enter replacement character: ")

# a. Frequency
print("Frequency:", s.count(c))

# b. Replace
print("Replaced:", s.replace(c, new))

# c. Remove first occurrence
print("First removed:", s.replace(c, "", 1))

# d. Remove all occurrences
print("All removed:", s.replace(c, ""))
```
### OUTPUT
<img width="1920" height="352" alt="5" src="https://github.com/user-attachments/assets/d906eddc-a28c-426c-92fb-2721880d5f69" />

### Explanation

`count()` returns how many times `c` appears. `replace(old, new)` replaces every match. Passing a third argument `1` limits it to the first match, and replacing with an empty string `""` deletes the character.
